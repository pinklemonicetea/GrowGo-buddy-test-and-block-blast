# 🧩 GrowGo: MBTI Buddy Test & Block Blast

An interactive mini-game collection developed as part of the **GrowGo** project, combining an MBTI personality-based friendship test with a classic Block Blast puzzle mechanic.

## ✨ Key Features
* **🧠 MBTI Buddy Compatibility Test:** A fun personality-based quiz that analyzes friend chemistry, interaction styles, and matching traits using MBTI psychology.
* **🧱 Block Blast Puzzle:** An engaging, fast-paced puzzle mini-game designed for casual and relaxing gameplay.
* **🌱 Part of GrowGo Ecosystem:** Built to complement the cozy simulation vibe and user experience of the main GrowGo project.

## 🛠️ Tools & Tech Stack
* **Frontend / Language:** C# (unity)
* **Design & UI/UX:** Figma (UI/UX Design, User Flow, and Interactive Prototyping)
* **Version Control:** Git & GitHub
